# Waultnet Core

A decentralized, permissionless protocol for general-purpose high-performance computing. 

## Vision
We reject centralized cloud gatekeeping. Waultnet transforms idle hardware into a global supercomputer, treating raw computational power as a transparent, community-governed public utility.

## Architecture
- **Protocol:** Proof of Compute History
- **License:** GPLv3

## Status
- **Phase:** Initialization
- **Development:** Active

## Transparency
We operate as an open-source collective. All financial and development activities are transparently managed via Open Collective.
